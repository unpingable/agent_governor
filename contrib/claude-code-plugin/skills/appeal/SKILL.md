---
description: Appeal a governor denial with justification
---

When a governor denial or violation exists, help prepare and file an appeal.
Gather from the user:

- Which denial or violation to appeal
- Justification for the exception
- Requested scope (which files, commands, or actions)
- Requested duration (one-time, session, or time-limited)
- Rollback plan if the exception causes problems

Use the governor MCP tools to file the exception via the violation resolver.
Report the exception ID and confirmation.
