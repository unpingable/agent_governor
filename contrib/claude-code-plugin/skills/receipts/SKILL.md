---
description: Inspect governor receipts for the current session
---

Use the governor MCP tools to list and summarize gate receipts for the
current session. Highlight:

- Total receipt count and verdict breakdown (pass/block/observe/warn)
- Most recent denied actions with reasons
- Appealed or overridden actions
- Missing receipt coverage (writes or commands without receipts)
- Session timeline of governance events

Default to showing the last 10 receipts unless the user asks for more.
