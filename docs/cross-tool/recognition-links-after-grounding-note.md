# Cross-tool doctrine note: recognition links after grounding, not before

## Status

**Cross-constellation doctrine stub — candidate, non-binding.** Filed 2026-06-19 under
AG custody (operator + ChatGPT, during the NQ monitoring-as-projection landing).
Records a sequencing rule for cross-office links. Routine register — it governs how
doctrine notes cite each other; it admits no architecture.

> cite-don't-extract tier. recognition link, not premise.

## The failure mode it guards

When two offices independently converge on the same shape — NQ's
"monitoring is a projection" arriving at the same demon as continuity's
projection-receipt family (stored ≠ true, signed ≠ witnessed) — the instinct is to
immediately cross-link them: "these are all one family, wire them together." That
instinct, acted on too early, launders **recognition into derivation** and trips two
things the constellation already named:

1. **It collapses the independent-derivation signal.** If NQ found the shape from its
   own code (`severity_rank`, `regime.rs`, the un-joined verdict lineage), that
   independent arrival is *corroboration* — worth more precisely because it was not
   seeded. Pre-load the local note with "you are a sibling of the projection-receipt
   family" and you can no longer tell whether the shape is in NQ's code or just in the
   framing. (The independence-firewall reflex.)
2. **It is noun-gluing before contact.** "A structure assembled from agreement instead
   of contact — the polish is the smell." A tidy "four notes, one demon, cross-link
   them" makes the doctrine prettier and more interconnected *before* the local finding
   has been corrected by the local grammar. The haunted-cathedral move, one level up.

## The rule

> When two offices independently converge on the same shape, add recognition links
> **only after** each local note is grounded in its own evidence and vocabulary.

Sequencing:

```text
before the local note exists:     no sibling link
during implementation:            cite the local note, not the sibling family
after the local note lands:        yes — one-line backlink, recognition tier
```

A recognition link is a **pointer**, never:

- a dependency the local note needs to stand,
- a shared abstraction the local office must adopt,
- a load-bearing premise ("therefore the family's type must be adopted").

The local note must say the **code-grounded local finding** ("`http/routes.rs`
recomputes request-time preflight verdicts with an ambient clock and no sealed
receipt"), not the imported abstraction ("NQ is an instance of the projection-receipt
family"). The second smells like doctrine looking for a place to sit.

## The counter-rule (do not over-correct into asceticism)

Do **not** wait forever. Once the local note is filed and its code facts are stable,
the independence signal has been *earned* — add the sibling backlink **immediately**.
After that point, refusing to link is fake asceticism; documentation should not pretend
the constellation has never met itself. The clean chain is:

```text
local evidence → local seam → later recognition
```

not:

```text
grand theory → local-evidence cosplay
```

## Firing case (provenance)

NQ's `MONITORING_PROJECTION_SEAM_CANDIDATE.md` / `OPERATOR_SURFACE_SPLIT_TRIPWIRE.md`
landed grounded in NQ code and vocabulary, with implementation citing the *local*
notes only. The recognition backlink to the projection-receipt family was deliberately
**held** until the note + code facts were stable, then added as a one-line `See also`.
This note generalizes that move.

## NON_CLAIMS

- Does not forbid cross-office links — it sequences them.
- Does not ratify any shared type or family abstraction.
- Applies to **independent convergence**; work explicitly derived from a shared kernel
  is a different case (cite the kernel up front).

## Doctrine lines

- Recognition links after grounding, not before.
- cite-don't-extract: a pointer, not a premise.
- Independent convergence is corroboration only if it stays independent until grounded.
- Don't wait forever — once grounded, link; refusing is fake asceticism.
