# Inspect it in 10 minutes (no install)

> STATUS: CANDIDATE (docs-professionalization D-2)

You can evaluate this system without running anything, because its output
is inspectable evidence, not logs you have to take on faith.

1. **Read the refusal gallery** — [../REFUSAL_GALLERY.md](../REFUSAL_GALLERY.md).
   Eight components, each refusing in 30 seconds, with the exact command,
   the verbatim refusal, and the typed reason field on the receipt. Most
   AI demos show success; this shows the system saying no, and why.

2. **Verify one receipt yourself** — [../../specimens/README.md](../../specimens/README.md).
   The specimen corpus is a checked-in real governed run: the queued work,
   the operator's approval act, the plan, the review packet. The README
   gives you the `sha256sum` commands to re-verify the digests by hand —
   no tooling, no trust in prose.

3. **Read what agents are not allowed to do** — [../NON_GRANTS.md](../NON_GRANTS.md).
   Nine structural non-grants (no self-approval, no authority from prose,
   no spend past a lapsed permission, …), each with the enforcing code
   cited by file and line and the test that pins it.

The take-away to test against your own skepticism: every claim in those
three documents is either runnable or checkable — and where it isn't, the
document says so instead of rounding up.
