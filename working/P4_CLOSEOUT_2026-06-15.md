## 2. What authority it consumes (and never co-authors)

Promotion is a **four-office classed act**; each office maps to a witness:

- **admissibility** → `PromotionEligible` predicate (`promotion_gate.py`)
- **act-standing** → operator basis bound to the reviewed bundle (`operator_basis.py`)
- **exactly-once spend** → a single content-addressed `PromotionReceipt`
- **durable custody** → `ControlBaseline` + content-addressed lineage

The mint consumes prior authority commits as *prior*, never self-citing:
`85601bd` (HIGH-prep doctrine + spec), `632414d` (raw-hex clarification), `e8cb8e2`
(the mint), `2e94dee` (operator-basis alignment).

**The fence (verbatim):** operator basis *authorizes attribution; it does not legitimize
promotion and cannot cure missing evidence.* A failing predicate refuses regardless of a
clean operator basis; a failing operator basis refuses regardless of a clean predicate.
Neither office substitutes for the other.

## 3. What it refuses

- predicate ineligible (insufficient count / stale / not-walkable / replay missing /
  replay failed / corpus-hash mismatch / operator-basis absent / open NonDischargeClaim /
  off-surface tunable / kernel-fuse-ratification side effect)
- `operator_basis_*` structural failures (bundle mismatch / post-attestation / stale /
  verdict-refused / claims-auto / clock-incompatible / missing binding)
- `operator_basis_weak_strong_mismatch` — a bundled weak shadow that does not equal
  `project(strong facts)` (the substitution seam, closed slice 2)
- a promoted-baseline revert that is not a fresh supersession ceremony (no silent undo;
  no `delete` path on the store)
